# Privacy Policy — Timestamp for Suno

**Last Updated: November 9, 2026**

## Overview (English)

**Timestamp for Suno** is a lightweight, open-source browser extension that displays song creation timestamps (`YYYY/MM/DD HH:mm:ss`) inline on `https://suno.com/`.

1. **No Data Collection**: This extension does **not** collect, transmit, store externally, or share any personal information, browsing history, authentication tokens, cookies, prompts, lyrics, or audio files.
2. **Local Processing Only**: All timestamp extraction and formatting happen 100% locally inside your browser tab on `https://suno.com/`.
3. **Local Cache (`chrome.storage.local`)**: The extension caches only `Clip ID (UUID) -> created_at (UTC ISO timestamp)` mappings in your browser's local storage (`chrome.storage.local`) to render timestamps quickly across page reloads. This data never leaves your device and is automatically removed when you uninstall the extension.
4. **No Third-Party Analytics or External Servers**: The extension does not use any analytics trackers, telemetry, or external backend servers.

## プライバシーポリシー（日本語）

**Timestamp for Suno** は、`https://suno.com/` の画面上に楽曲の作成日時（`YYYY/MM/DD HH:mm:ss`）をインライン表示するオープンソースの Chrome 拡張機能です。

1. **ユーザーデータの収集・外部送信なし**: 本拡張機能は、個人情報、閲覧履歴、認証トークン、Cookie、プロンプト、歌詞、音声データなどを一切収集せず、外部サーバーへ送信・共有することもありません。
2. **ブラウザ内完結の処理**: 日時の抽出・タイムゾーン変換・表示はすべてお使いのブラウザ内（`https://suno.com/` 上）でのみ完結します。
3. **ローカルキャッシュ (`chrome.storage.local`)**: 再読み込み時の表示を高速化するため、`Clip ID (UUID)` と `created_at (UTC作成日時)` の対応のみをブラウザ内の `chrome.storage.local` に保存します。このデータは端末外に出ることはなく、拡張機能をアンインストールすると削除されます。
4. **外部解析ツール不使用**: アクセス解析ツールや外部バックエンドサーバーは一切使用していません。
